Detailed Description

Joystick and button interface for the Digitally Controlled FM Radio Receiver.

Defines pin numbers and button identifier constants for the 7-direction joystick module, and declares the public API.

◆ JoyStickInit()

void JoyStickInit ( )

Initialise all joystick GPIO pins as INPUT_PULLUP.

Must be called once in setup() before any call to ReadButton().

Uses internal pull-up resistors so the pins read HIGH when idle and LOW when the corresponding button is pressed.
