Detailed Description

OLED display interface for the Digitally Controlled FM Radio Receiver.

Wraps the Adafruit SSD1306 library and provides simple screen drawing functions for the radio, menus and scan configuration screens.

◆ DisplayInit()

void DisplayInit ( )

Initialise the SSD1306 display and show the splash screen.

Attempts to start the display over I2C. If initialisation fails the function halts in an infinite loop and prints an error to Serial. On success it shows the project name and author for 2 seconds.

Halts with an infinite loop if the display cannot be found on I2C.
